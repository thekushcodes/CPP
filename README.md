# C++ Practice Programs

This repository contains my C++ practice programs created while following the CodeWithHarry C++ tutorial playlist.

I originally wrote these programs during my C++ learning journey. This repository serves as a collection of the programs and concepts I practiced while learning C++.

## 📚 Topics Covered

The programs in this repository cover a variety of C++ concepts, including:

* Introduction to C++
* Variables and Data Types
* Input and Output
* Operators
* Conditional Statements (`if`, `else if`, `else`, `switch`)
* Loops (`for`, `while`, `do-while`)
* Arrays
* Strings
* Functions
* Function Arguments and Return Values
* Pointers
* References
* Structures, Unions, and Enumerations
* Classes and Objects
* Constructors and Destructors
* Access Modifiers
* Member Functions
* Static Data Members and Functions
* Object-Oriented Programming (OOP)
* Inheritance
* Multiple and Multilevel Inheritance
* Polymorphism
* Virtual Functions
* Friend Functions and Friend Classes
* Templates
* Exception Handling
* File Handling
* STL (Standard Template Library)
* Other C++ concepts and practice programs

## 📁 File Naming

The files are generally named according to the tutorial sequence, for example:

```text
tut01.cpp
tut02.cpp
tut03.cpp
...
```

Using leading zeros in the filenames helps keep them properly sorted.
